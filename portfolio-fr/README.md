# Portfolio de Kim Ngoc Pham

Portfolio professionnel en français, conçu pour GitHub Pages.

## Mise en ligne sur GitHub

1. Décompressez l'archive téléchargée.
2. Dans votre repository GitHub, cliquez sur **Add file**, puis **Upload files**.
3. Importez `index.html`, `style.css` et `script.js` à la racine du repository. Ne téléversez pas le dossier parent `portfolio-fr` lui-même.
4. Validez avec **Commit changes**.
5. Ouvrez **Settings → Pages**.
6. Dans **Source**, choisissez **Deploy from a branch**.
7. Sélectionnez la branche **main**, le dossier **/(root)**, puis cliquez sur **Save**.

## Informations à personnaliser

Dans `index.html`, recherchez les deux commentaires contenant le mot `Remplacez` et modifiez :

- `votre.email@exemple.fr` avec votre adresse e-mail ;
- `#` avec l'URL de votre profil LinkedIn.

Vous pouvez également ajouter un fichier CV et un bouton de téléchargement lorsque votre CV sera prêt.
